### Вариант 9. Циклический сдвиг вправо

Реализуйте void rotateRight(int *a, int n), выполняющую циклический сдвиг массива на одну позицию вправо: последний элемент становится первым. Используйте только одну дополнительную переменную. Обработайте массив из одного элемента.
